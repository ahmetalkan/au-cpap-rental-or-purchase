# Australian CPAP rental versus purchase: a decision worksheet

A worksheet for renting versus buying CPAP in Australia, with Healthdirect, Better Health Channel and Sleep Health Foundation sources.

This is a free, standalone mini-resource. The live HTML page is intended to be served from:

- Render: `https://au-cpap-rental-or-purchase.onrender.com/`
- GitHub Pages: `https://ahmetalkan.github.io/au-cpap-rental-or-purchase/`

It cites public pages on [sleepclinicsau.com](https://sleepclinicsau.com/) and official reference sources listed at the bottom of the page. Nothing here is a substitute for advice from a qualified professional.
